Introduction to CSS Flexbox

Overview

Flexbox, short for Flexible Box Layout, is a CSS layout model designed to provide an efficient way to align and distribute space among items in a container. It excels at creating responsive designs and dynamic alignment of elements, especially when the size of your content is unknown or dynamic.

The main idea behind the flex layout is to give the container the ability to alter its items’ width/height to best fill the available space. This is especially helpful when designing layouts for different screen sizes or device orientations.

Unlike traditional layout methods like floats or inline-block, Flexbox simplifies common tasks like vertically centering elements, equal spacing, and layout rearrangement.

Basic Terminology

Before diving into the syntax, it's important to understand some key terms in Flexbox:

  • Flex container: The parent element where flex layout is applied.
  • Flex items: The children of the flex container.
  • Main axis: The primary axis along which flex items are laid out.
  • Cross axis: The axis perpendicular to the main axis.
  • Direction: Controlled by the flex-direction property.

Understanding these terms will help you navigate and use Flexbox effectively. Many properties depend on whether you're working along the main or cross axis.

Creating a Flex Container

To use Flexbox, you need to define a flex container by setting the display property to flex or inline-flex.

Here’s how you declare a flex container:


  .container {
    display: flex;
  }

Once a container becomes a flex container, all its direct children become flex items. This changes their layout behavior and allows you to use Flexbox properties to manage spacing, alignment, and order.

You can also use inline-flex instead of flex if you want the container to behave like an inline element while still applying Flexbox rules.

Flex Direction

The flex-direction property defines how flex items are placed in the flex container. It determines the main axis.

Here are the available values:

  • row (default): Items are placed from left to right.
  • row-reverse: Items are placed from right to left.
  • column: Items are placed from top to bottom.
  • column-reverse: Items are placed from bottom to top.

Example:


  .container {
    display: flex;
    flex-direction: row-reverse;
  }
Justifying Content

The justify-content property controls how flex items are aligned along the main axis.

Common values include:

  • flex-start: Aligns items to the start of the container.
  • flex-end: Aligns items to the end of the container.
  • center: Centers items along the main axis.
  • space-between: Evenly distributes items, first item at start and last at end.
  • space-around: Equal space around all items.
  • space-evenly: Equal space between all items, including the ends.

Example:


  .container {
    display: flex;
    justify-content: space-between;
  }
